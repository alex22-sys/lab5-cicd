CI/CD Deployment with GitHub Actions

Вебзастосунок автоматично збирається у Docker image, публікується в Docker Hub та оновлюється на Azure VM за допомогою Watchtower.

pipeline ready: lint, build, push, deploy

CI

GitHub Actions запускається після push у main, перевіряє HTML/CSS через Prettier і готує код до збірки.

CD

Pipeline збирає Docker image на базі nginx і завантажує його в Docker Hub з тегами latest та SHA коміту.

Deploy

Watchtower на Azure VM перевіряє Docker Hub, завантажує нову версію image і перезапускає контейнер застосунку.
